## Evidence Classes

A retained matrix report is generated by
`tools/compatibility/matrix.mjs`, binds a clean source identity, validates the
contracted tool versions and command sequence, and participates in the formal
local acceptance gate.

A supplemental platform record documents a complete local execution on an
environment outside the contracted matrix. It can provide portability evidence,
but it cannot satisfy a differently shaped matrix cell or change the acceptance
contract.

## Verification

Verify the retained platform reports and final gate with:

```sh
bun tools/compatibility/matrix.mjs --verify-all
bun tools/acceptance/finalize.mjs --verify --require-pass
```

The expected matrix summary is two of two required macOS cells complete, with
both optional Linux x64 cells still reported as missing.
