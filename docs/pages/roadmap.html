Research

Bootstrap chain

Generation 0
Emacs Lisp seed + program.eli → program.js

Generation 1
Emacs Lisp seed + compiler.eli → compiler.js

Generation 2
compiler.js + compiler.eli → next-compiler.js

Self-hosting is complete only when both compilers pass the same conformance suite and the generated compiler can reproduce itself without semantic drift.

A path back into Emacs

Once portable Eliscript runs efficiently in JavaScriptCore, Emacs can retain editor state and interaction while delegating coarse-grained parsing, indexing, transformation, and publishing workloads.

Bun is a compute host, not a replacement for Emacs. End-to-end measurements must include worker startup, serialization, transport, and result application.

Principles that stay fixed

  • Emacs remains enough to build the seed compiler.
  • Generated code stays readable and standards-based.
  • JavaScript interop is explicit rather than magical.
  • Compatibility never blocks a clearly better language design.
  • Self-hosting is proven by reproducibility and conformance, not branding.
